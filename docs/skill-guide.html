천안시 AI 행정 문서 작성 꾸러미 — ⑤ 보도자료 스킬 · ⑥ 결과보고 스킬 · 속기록 정리 스킬

어떤 스킬인가요?

스킬은 Claude에게 「이 일은 이렇게 하라」는 작업 설명서와 한글 양식을 미리 넣어 두는 기능입니다. 한 번 올려 두면 파일만 첨부해도 같은 양식으로 문서가 나옵니다.

⑤ 보도자료 스킬 (행사 전 · 행사 후)

넣는 것 행사 전: 계획서(또는 보고요지) / 행사 후: 계획서 + 결과보고(또는 속기록)
나오는 것 천안시 보도자료 한글 파일(.hwpx) — 담당 칸·제목·부제·기사체 본문

행사 전 배포용 받기 행사 후 배포용 받기

⑥ 결과보고 스킬

넣는 것 계획서(또는 보고요지) + 속기록(녹취)
나오는 것 천안시 「결과 보고」 한글 파일(.hwpx) — 표지·총평·간담회 개요·기관별 의견수렴·향후계획·붙임(참석자 명단·사진)

결과보고 스킬 받기

[별도] 속기록만 정리하고 싶을 때

넣는 것 계획서(또는 보고요지) + 속기록(녹취)
나오는 것 속기록 정리 한글 파일(.hwpx) — 제목 상자·행사 개요·기관·직위·성명·발언내용·핵심요약·시장님답변·관련부서 표

속기록 정리 스킬 받기

보도자료는 ⑤, 결과보고서 한 부가 필요하면 ⑥, 발언을 기관별 표로만 정리하고 싶으면 속기록 정리를 쓰세요. 여러 스킬을 모두 올려 두어도 됩니다.

1단계 · 준비 (처음 한 번만)

  1. 인터넷 창(크롬·엣지)에서 claude.ai에 로그인합니다.
  2. 왼쪽 아래 내 이름(프로필)을 눌러 설정으로 들어갑니다.
  3. 기능(Capabilities)에서 코드 실행 및 파일 생성을 켭니다. 이것이 꺼져 있으면 스킬이 한글 파일을 만들지 못합니다.

메뉴 이름은 Claude 화면 버전에 따라 조금 다를 수 있습니다. 「스킬」 메뉴가 보이지 않으면 요금제나 기관 관리자 설정에서 스킬 사용이 막혀 있는지 확인하세요.

2단계 · 스킬 올리기 (스킬마다 처음 한 번만)

  1. 위의 스킬 받기 단추로 zip 파일을 내려받습니다. 압축을 풀지 마세요. zip 그대로 올립니다.
  2. Claude 설정 → 기능 → 스킬로 갑니다.
  3. 스킬 업로드를 누르고 내려받은 zip 파일을 고릅니다.
  4. 목록에 cheonan-press-release-before / -after(보도자료), cheonan-meeting-result-report(결과보고), meeting-result-table(속기록 정리)이 생기고 켜져 있으면 끝입니다.

3단계 · 사용하기 (문서가 필요할 때마다)

  1. Claude 왼쪽 위 새 채팅을 누릅니다.
  2. 입력 칸의 +(파일 첨부)로 필요한 파일을 올립니다.
    · 계획서(또는 보고요지) — 참석자 명단이 든 .hwpx 파일
    · 속기록 — 클로바노트 등 녹취 .txt 또는 .hwpx (보도자료 행사 전은 계획서만, 행사 후는 계획서 + 결과보고도 됩니다)
  3. 첨부한 뒤 실행(Enter)합니다. 아래 요청문을 함께 붙여 넣으면 Claude가 스킬을 더 정확히 고릅니다.

    ⑤ 보도자료가 필요할 때

    (행사 전) 첨부한 계획서로 행사 예고 보도자료(.hwpx)를 만들어 줘. cheonan-press-release-before 스킬을 사용해 줘. (행사 후) 첨부한 계획서와 결과보고로 행사 결과 보도자료(.hwpx)를 만들어 줘. cheonan-press-release-after 스킬을 사용해 줘.
    복사했습니다

    ⑥ 결과보고서가 필요할 때

    첨부한 계획서(또는 보고요지)와 속기록으로 천안시 간담회 결과보고서(.hwpx)를 만들어 줘. cheonan-meeting-result-report 스킬을 사용해 줘.
    복사했습니다

    속기록만 정리할 때

    첨부한 계획서(또는 보고요지)와 속기록으로 기관별 속기록 정리 표(.hwpx)를 만들어 줘. meeting-result-table 스킬을 사용해 줘.
    복사했습니다
  4. 몇 분 뒤 Claude가 한글 파일을 만들어 줍니다. 파일을 눌러 내려받기합니다.
  5. 한글에서 열어 확인합니다. Claude 답변 끝에 적힌 확인 필요 항목(관련부서 추정, 발언자 확인 등)을 먼저 고치세요.

Claude가 부서명·행사 목적 같은 빠진 정보를 물어보면 채팅으로 답하면 됩니다. 결과가 마음에 들지 않으면 같은 채팅에서 「총평을 4줄로 줄여 줘」처럼 고쳐 달라고 하세요.

자주 묻는 질문

상황이렇게 하세요
.hwp 파일이라 안 읽혀요한글에서 다른 이름으로 저장 → 파일 형식 HWPX(.hwpx)로 저장한 뒤 다시 첨부하세요.
스킬을 안 쓰고 엉뚱하게 만들어요요청문에 스킬 이름(cheonan-press-release-before·after / cheonan-meeting-result-report / meeting-result-table)이 들어 있는지 확인하고, 설정 → 기능 → 스킬에서 켜져 있는지 보세요.
결재란 직위를 바꾸고 싶어요결과보고 스킬은 결재란을 양식 그대로 고정합니다. 내려받은 뒤 한글에서 직접 고치세요.
회의록(붙임)도 넣고 싶어요결과보고 스킬은 기본으로 회의록을 붙이지 않습니다. 요청문 끝에 「붙임에 회의록도 넣어 줘」를 덧붙이세요.
사진을 넣고 싶어요행사 사진(jpg·png)을 함께 첨부하고 「붙임 사진에 넣어 줘」라고 적으세요. 없으면 「별도 첨부」로 남습니다.
글꼴이 다르게 보여요PC에 양식 글꼴(나눔스퀘어 ExtraBold, HY헤드라인M, HY견명조, 강원교육튼튼, 한컴산뜻돋움 등)이 없으면 한글이 비슷한 글꼴로 보여 줍니다. 내용에는 문제가 없습니다.

개인정보·보안 — 속기록에는 참석자 실명과 발언이 들어 있습니다. Claude에 파일을 올리기 전에 기관의 생성형 AI 이용 지침(외부 AI에 올려도 되는 자료인지)을 꼭 확인하세요. 꾸러미 웹 자체는 입력 내용을 밖으로 보내지 않지만, 스킬은 Claude(외부 서비스)에서 동작합니다.
